## Почему Ochre

- **Чип, а не среднее значение.** Обычные мониторы показывают один процент загрузки CPU. Ochre рисует процессор так, как он устроен: ядра по кластерам (Super и Performance на M5, Performance и Efficiency на M1–M4), у каждого своя загрузка, плюс полоса ядер GPU. Один зависший поток видно сразу.
- **Цвет означает только нагрев.** Интерфейс графитовый и бумажный. Цвет появляется только там, где что-то работает на пределе: янтарь, затем угли, затем жар. Это читается с одного взгляда даже издалека.
- **Почти не нагружает систему.** Замер на M5 Pro: около 0,7% одного ядра и 13 МБ памяти при закрытой панели. Температуры читаются раз в 15 с в фоне и раз в 2 с при открытой панели.
- **Нативное приложение.** Swift, SwiftUI и AppKit с Liquid Glass. Без Electron, фоновых служб, пароля администратора и расширений ядра.
- **Приватность.** Никаких сетевых запросов, аналитики и учётных записей. Все данные берутся из локальных системных интерфейсов и не покидают Mac.
- **Оповещения не дёргают зря.** Порог должен продержаться заданное время, поэтому пятисекундный всплеск не вызовет уведомления.

## Возможности

Набор сегментов выбирается в настройках: **мини-кристалл**, **мини-график CPU**, **загрузка CPU**, **память**, **температура** и **скорость сети**. У каждого сегмента фиксированная ширина, поэтому строка меню не прыгает при смене цифр. Пока оповещение активно, его сегмент горит красным. VoiceOver читает весь значок одной фразой.

### Карта кристалла и CPU

<img src="docs/images/tab-cpu.jpg" align="right" width="300" alt="Вкладка CPU: карта кристалла и история загрузки всего процессора, ядер Super и ядер Performance">

- Для каждого ядра своя плитка табло с загрузкой в процентах. Плитка перещёлкивается, когда значение меняется.
- Ядра сгруппированы по уровням производительности, как их сообщает macOS; у каждого кластера своя температура.
- Полоса GPU: по ячейке на каждое ядро GPU, загорается по загрузке.
- История загрузки всего процессора и каждого кластера.
- На вкладке **Обзор** также есть мини-графики процессора, памяти, сети и диска и три самых загруженных процесса.

### Датчики

<img src="docs/images/tab-sensors.jpg" align="right" width="300" alt="Вкладка датчиков: температуры по группам, обороты вентиляторов, загрузка GPU, мощность системы и состояние батареи">

- Температуры по группам: CPU (все датчики кристалла, раскрывающийся список), SSD, батарея, контроллер питания.
- Обороты вентиляторов, загрузка GPU и потребление системы в ваттах.
- Батарея: заряд, циклы, здоровье, мощность и состояние зарядки.

<br clear="right">

### Процессы и оповещения

- Вкладка **Процессы** показывает самые активные процессы по CPU или по памяти. Клик по строке копирует PID.
- Оповещения о **температуре CPU**, **загрузке CPU**, **давлении памяти** и **нехватке места на диске**. Вы задаёте порог и сколько он должен продержаться, например 95 °C в течение 30 с. При срабатывании приходит системное уведомление, а сегмент в строке меню становится красным.
- Интервал обновления 1, 2 или 5 секунд и запуск при входе в систему.

## Установка

**[Скачать Ochre 1.0.0](https://github.com/aesarva/ochre/releases/download/v1.0.0/Ochre-1.0.0.dmg)** (DMG, 7 МБ, Apple Silicon и Intel). Откройте его и перетащите Ochre в «Программы». Приложение подписано сертификатом Developer ID и нотаризовано Apple, поэтому открывается без предупреждений Gatekeeper. Все версии — на странице [Releases](../../releases).

### Сборка из исходников

Нужны macOS 26 или новее и Xcode 26 (Swift 6.2).

```sh
git clone https://github.com/aesarva/ochre.git
cd ochre
scripts/build-app.sh              # universal build/Ochre.app (arm64 + x86_64)
# ARCHS=arm64 scripts/build-app.sh  # только Apple Silicon, быстрее
cp -R build/Ochre.app /Applications/
open /Applications/Ochre.app
```

Ochre живёт только в строке меню, значка в Dock нет. Настройки открываются кнопкой **Настройки** внизу панели. Для оповещений разрешите уведомления при первом запросе.

Если `xcode-select` указывает на Command Line Tools, перед командами `swift` задайте `export DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer`. Скрипты сборки делают это сами.

## Как это работает

| Метрика | Источник |
| --- | --- |
| Загрузка каждого ядра | `host_processor_info` |
| Кластеры ядер | sysctl `hw.nperflevels`, `hw.perflevel*` |
| Загрузка и число ядер GPU | статистика `IOAccelerator` в IORegistry |
| Память, давление, swap | `host_statistics64`, `kern.memorystatus_vm_pressure_level`, `vm.swapusage` |
| Сеть | счётчики интерфейсов `NET_RT_IFLIST2` |
| Диск | статистика `IOBlockStorageDriver`, ёмкость тома |
| Температуры (Apple Silicon) | датчики IOHID event system |
| Вентиляторы, мощность, датчики Intel | SMC |
| Батарея | `AppleSmartBattery` |
| Процессы | `proc_pid_rusage`, `proc_pidpath` |

Код разделён на две части. **MetricsCore** содержит сборщики метрик, опрос, историю, движок оповещений и логику отображения и покрыт юнит-тестами. **Ochre** — приложение на SwiftUI и AppKit поверх него. К датчикам температуры и SMC код обращается через небольшую прослойку на C (`CPrivateAPI`).

```
Sources/
  CPrivateAPI/   объявления на C для IOHID и SMC
  MetricsCore/   сборщики, опрос, оповещения, отображение (тестируется)
  Ochre/         значок в строке меню, панель, настройки, уведомления
Tests/           MetricsCoreTests
Resources/       Info.plist, иконка Icon Composer
scripts/         build-app.sh, release.sh
site/            статический лендинг (RU/EN)
```

## Ограничения

- Датчики читаются через приватные интерфейсы macOS (IOHID и SMC). Их названия и набор отличаются между моделями Mac, а обновление macOS может их изменить. По этой же причине Ochre нет в Mac App Store.
- На Intel-маках температуры CPU недоступны, потому что там нет HID-датчиков. Вентиляторы и мощность читаются через SMC.
- Процессы других пользователей и root без повышенных прав недоступны, поэтому они пропускаются.
- Интерфейс пока только на русском.

## Разработка

```sh
swift test                         # юнит-тесты MetricsCore
ARCHS=arm64 scripts/build-app.sh   # быстрая локальная сборка
```

Отладочные аргументы запуска:

- `-OpenPopoverOnLaunch YES` открывает панель при запуске.
- `-PopoverTab <вкладка>` задаёт стартовую вкладку.
- `-SnapshotDir <путь>` сохраняет PNG значка в строке меню, всех вкладок и настроек без разрешения на запись экрана.

Ветки: `main` содержит только релизы, `develop` — ветка интеграции, каждое изменение делается в отдельной ветке и сливается в `develop`. Подробнее в [CONTRIBUTING.md](CONTRIBUTING.md).

### Выпуск версии

`scripts/release.sh <версия>` собирает universal-приложение, подписывает его сертификатом Developer ID, нотаризует и прикрепляет тикет к приложению и DMG, затем проверяет результат через Gatekeeper. Результат — `dist/Ochre-<версия>.dmg`.

Однократная подготовка:

1. Вступить в [Apple Developer Program](https://developer.apple.com/programs/).
2. Создать сертификат **Developer ID Application**: Xcode → Settings → Accounts → Manage Certificates.
3. Сохранить профиль нотаризации:
   ```sh
   xcrun notarytool store-credentials Ochre --apple-id <apple-id> --team-id <TEAMID> --password <пароль-приложения>
   ```

Если сертификатов несколько, нужный выбирается через `SIGN_IDENTITY="Developer ID Application: …"`. `scripts/release.sh <версия> --unsigned` выполняет все шаги, кроме подписи и нотаризации.

После публикации релиза обновите ссылку на скачивание в разделе **Установка** обоих README.

Настройки сборок со старыми идентификаторами (`com.alexsarva.StatusApp`, `local.statusapp.StatusApp`) переносятся при первом запуске.

### Лендинг

`site/` — статическая страница без сборки. Локальный просмотр: `cd site && python3 -m http.server`. Перед публикацией положите `dist/Ochre.dmg` рядом с `site/index.html`, на него ведут кнопки «Скачать».
