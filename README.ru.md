## Главное

- **Настоящий чип, а не среднее значение.** Ядра нарисованы так, как устроен процессор: по кластерам (Super и Performance на M5, Performance и Efficiency на M1–M4), у каждого своя загрузка, ниже полоса ядер GPU. Один зависший поток виден сразу.
- **Цвет — это нагрев.** Интерфейс графитовый и бумажный. Цвет появляется только там, где идёт работа: янтарь, потом жар, потом красный.
- **Почти не нагружает Mac.** Около 0,5% одного ядра и 14 МБ памяти при закрытой панели (замер на M5 Pro). Когда вы не смотрите, Ochre опрашивает систему реже.
- **Нативное.** Swift, SwiftUI и AppKit с Liquid Glass. Без Electron, фоновых демонов, пароля администратора и расширений ядра.
- **Приватное.** Никакой аналитики и аккаунтов. Единственный сетевой запрос — проверка обновлений на GitHub раз в сутки: никаких данных о системе, отключается в настройках.
- **Оповещения, которые ждут.** Порог должен продержаться заданное время, прежде чем придёт уведомление, поэтому короткие всплески не беспокоят.

## Возможности

**Строка меню.** Соберите значок из нужных сегментов: мини-кристалл, график CPU, CPU %, память %, температура и скорость сети. У сегментов фиксированная ширина, поэтому строка меню не дёргается, а сегмент краснеет, пока активно его оповещение.

**CPU и GPU.** По плитке-табло на каждое ядро, плитка перелистывается при смене загрузки. У каждого кластера своя температура, у всего CPU и каждого кластера своя история загрузки. Ядра GPU — полосой ниже.

**Память.** Память приложений, неперемещаемая, сжатая и кэш на одной полосе, а также история, давление памяти и своп.

**Сеть и диск.** Скорость загрузки и отдачи с пиками и историей, активный интерфейс и трафик с момента запуска. Свободное место на загрузочном диске и скорость чтения и записи.

**Датчики.** Все датчики температуры по группам (CPU, SSD, батарея, питание), скорость вентиляторов, загрузка GPU, общая мощность системы, а также заряд, циклы и состояние батареи.

**Процессы.** Самые активные процессы по CPU или по памяти. Клик по строке копирует PID.

**Оповещения.** Температура CPU, загрузка CPU, давление памяти и нехватка места на диске. Задайте порог и сколько он должен продержаться, например 95 °C в течение 30 секунд.

**Обновления.** Раз в сутки Ochre проверяет, не вышла ли новая версия. Если вышла, на значке появляется точка, а в панели — кнопка **«Установить и перезапустить»**: одно нажатие скачивает обновление, проверяет подпись, заменяет приложение и запускает новую версию.

**Настройки.** Обновление раз в 1, 2 или 5 секунд, запуск при входе в систему и автоматическая проверка обновлений.

## Установка

1. [Скачайте DMG](https://github.com/aesarva/ochre/releases/download/v1.1.0/Ochre-1.1.0.dmg) (7 МБ). Предыдущие версии — на странице [Releases](../../releases).
2. Откройте его и перетащите **Ochre** в **Программы**.
3. Запустите Ochre. Он появится только в строке меню, без значка в Dock. Нажмите на него, чтобы открыть панель. Настройки (шестерёнка) и выход (кнопка питания) — внизу панели.

Если включить оповещения, macOS один раз попросит разрешение на уведомления. Других разрешений Ochre не нужно.

**Удаление:** выключите «Запускать при входе» в настройках, закройте Ochre и перенесите его в Корзину. Чтобы удалить и настройки, выполните `defaults delete com.alexsarva.Ochre`.

## Вопросы и ответы

<details>
<summary><b>Почему Ochre нет в Mac App Store?</b></summary>

Температуры, вентиляторы и мощность читаются через IOHID и SMC. Это закрытые интерфейсы macOS, и песочница App Store их не пропускает. Ochre распространяется напрямую, подписан сертификатом Developer ID и нотаризован Apple.
</details>

<details>
<summary><b>Работает ли он на Intel?</b></summary>

Да, приложение универсальное. На Intel нет HID-датчиков температуры, поэтому температуры CPU там не показываются. Вентиляторы и мощность по-прежнему читаются из SMC.
</details>

<details>
<summary><b>Не посадит ли он батарею?</b></summary>

Нет. При закрытой панели Ochre опрашивает систему с выбранным интервалом, а температуры читает раз в 15 секунд. Частый опрос (температуры раз в 2 секунды и список процессов) идёт только при открытой панели.
</details>

<details>
<summary><b>Как обновить?</b></summary>

Ochre проверяет обновления раз в сутки и показывает новую версию в панели — нажмите **«Установить и перезапустить»**. Проверить сразу можно в «Настройки → Общие». В версии 1.0.0 обновлятеля ещё нет, её один раз обновите вручную, скачав новый DMG. Запускайте Ochre из «Программ»: открытый прямо из образа DMG, он не может обновить себя и говорит об этом.
</details>

<details>
<summary><b>Почему в списке не все процессы?</b></summary>

Процессы root и других пользователей нельзя прочитать без повышенных прав, а Ochre их не запрашивает.
</details>

<details>
<summary><b>Датчик называется странно или его нет.</b></summary>

Названия и набор датчиков отличаются от модели к модели и могут меняться с обновлениями macOS. [Создайте issue](../../issues) с моделью Mac и скриншотом вкладки «Датчики».
</details>

## Как это работает

| Метрика | Источник |
| --- | --- |
| Загрузка каждого ядра | `host_processor_info` |
| Кластеры ядер | sysctl `hw.nperflevels`, `hw.perflevel*` |
| Загрузка и число ядер GPU | статистика IORegistry `IOAccelerator` |
| Память, давление, своп | `host_statistics64`, `kern.memorystatus_vm_pressure_level`, `vm.swapusage` |
| Сеть | счётчики интерфейсов `NET_RT_IFLIST2` |
| Диск | статистика `IOBlockStorageDriver`, ёмкость тома |
| Температуры (Apple Silicon) | датчики IOHID event system |
| Вентиляторы, мощность, датчики Intel | SMC |
| Батарея | `AppleSmartBattery` |
| Процессы | `proc_pid_rusage`, `proc_pidpath` |

```
Sources/
  CPrivateAPI/   объявления C для IOHID и SMC
  MetricsCore/   сборщики, опрос, история, оповещения, представление (покрыто тестами)
  Ochre/         значок в строке меню, панель, настройки, уведомления
Tests/           MetricsCoreTests
scripts/         build-app.sh, release.sh
site/            лендинг (EN/RU)
```

## Сборка из исходников

Нужны macOS 26 и Xcode 26 (Swift 6.2).

```sh
git clone https://github.com/aesarva/ochre.git
cd ochre
scripts/build-app.sh                # universal build/Ochre.app
ARCHS=arm64 scripts/build-app.sh    # только Apple Silicon, быстрее
open build/Ochre.app
```

Тесты запускаются командой `swift test`. Если `xcode-select` указывает на Command Line Tools, добавьте перед ней `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer`.
