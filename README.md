# StatusApp

Системный монитор в строке меню macOS (CPU, память, диск, сеть, GPU, батарея, датчики, процессы).

- Требования: macOS 14+, Xcode (Swift 6). Если `xcode-select` указывает на Command Line Tools, перед командами задайте `export DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer`.
- Тесты: `swift test`.
- Сборка: `scripts/build-app.sh` собирает `build/StatusApp.app` (ad-hoc подпись).
- Установка: скопируйте `build/StatusApp.app` в `/Applications` и запустите; приложение живёт только в строке меню (`LSUIElement`).
- Оповещения (температура CPU, загрузка CPU, давление памяти, свободное место) настраиваются в окне настроек; при срабатывании показывается системное уведомление и красная подсветка. Разрешите уведомления при первом запросе.
- Температура обновляется раз в 15 с, пока панель закрыта (экономия CPU); при открытой панели интервал 2 с.
- Отладочные аргументы запуска: `-OpenPopoverOnLaunch YES` (открыть панель), `-PopoverTab <вкладка>` (стартовая вкладка), `-SnapshotDir <путь>` (сохранить PNG строки меню и вкладок для отладки).
- Известные ограничения: датчики читаются через приватные API (SMC/IOHID) и могут отличаться между моделями Mac; процессы других пользователей и root недоступны, они пропускаются.
