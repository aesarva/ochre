# StatusApp — визуальный редизайн «Карта кристалла» на Liquid Glass

Дата: 2026-10-15
Статус: дизайн согласован, ожидает ревью спецификации
Базовая спецификация: `docs/superpowers/specs/2026-10-15-status-app-design.md` (функциональность не меняется, кроме перечисленного здесь)

## 1. Цель

Сделать утилиту современной и узнаваемой: родной для macOS 26+ материал Liquid Glass и одна фирменная деталь — **карта кристалла** чипа пользователя (кластеры ядер CPU и GPU), подсвеченная по нагрузке. Деталь повторяется в строке меню как **мини-кристалл**.

Критерии успеха:
- С одного взгляда на строку меню и на «Обзор» видно, какие ядра нагружены и не перегрет ли Mac.
- Интерфейс следует системной теме (светлая/тёмная) и обоям за счёт системного стекла.
- Цели по ресурсам из базовой спецификации §1 сохраняются при закрытой панели (CPU < 1 %, память по phys_footprint < 50 МБ).

Не цели: новые метрики, изменения сборщиков данных, поддержка macOS < 26, локализация.

## 2. Платформа

- Минимальная версия поднимается до **macOS 26** (`platforms: [.macOS(.v26)]`, `LSMinimumSystemVersion 26.0`) — ради настоящего Liquid Glass API SwiftUI (`glassEffect`, `GlassEffectContainer`, стеклянные стили кнопок). Имитация материалами и ветки `#available` не делаются.

## 3. Визуальная система

### 3.1 Принцип «цвет = нагрев»
Единственный хроматический цвет интерфейса — шкала нагрева. Всё остальное монохромно (системные `primary`/`secondary`, стекло). Красное/янтарное всегда означает «горячо», никогда не декор. Отдельных цветов «на метрику» нет.

### 3.2 Шкала нагрева (`HeatScale`, в MetricsCore)
По загрузке 0…100 %:

| Ступень | Цвет | Диапазон |
|---|---|---|
| Холодное стекло | системный `primary` с прозрачностью 12 % | 0–20 % |
| Янтарь | `#FFC46B` | 20–60 % |
| Угли | `#FF8A5C` | 60–90 % |
| Жар | `#FF5A4E` | > 90 % |

Между опорными точками (20 %→янтарь, 60 %→угли, 90 %→жар) цвет интерполируется линейно в RGB; от 0 до 20 % — холодное стекло без интерполяции. Любое активное оповещение окрашивает соответствующее значение в «Жар» независимо от шкалы.

Шкала температур (для вкладки «Сенсоры»): < 60° нейтрально, 60–80° янтарь, 80–95° угли, > 95° жар (ступенчато, без интерполяции).

### 3.3 Типографика
Только системные шрифты: SF Pro для текста, SF Pro Rounded для крупных чисел; все цифры табличные (`monospacedDigit`). Без капслока в подписях, без декоративных надписей над разделами — заголовок раздела только там, где он несёт смысл.

### 3.4 Материал и форма
- Фон панели — системное стекло `NSPopover` macOS 26.
- Карта кристалла — в отдельной стеклянной «линзе» (`GlassEffectContainer` + `glassEffect` со скруглением ~16 pt).
- Переключатель вкладок — стеклянная капсула.
- Других карточек нет: метрики — строки с тонкими разделителями.

### 3.5 Движение
Только в ответ на данные или действие пользователя: ячейка ядра/полоска плавно меняет цвет за 0.6 с (`easeInOut`); подсветка выбранной вкладки переезжает за 0.25 с. При включённом «Уменьшить движение» (`accessibilityReduceMotion`) — без анимации.

## 4. Панель

Ширина 340 pt.

### 4.1 Вкладки
В капсуле всегда видны: **Обзор, CPU, Память, Сеть, Диск**; кнопка **«Ещё»** открывает меню с **Сенсоры** и **Процессы**. Выбранная вкладка из «Ещё» подсвечивает кнопку «Ещё».

### 4.2 Обзор
```
[капсула вкладок]
╭ линза ───────────────────────────╮
│ Super                       44°  │  ← имя кластера; температура CPU (общая, одна) у первого кластера
│ ▢▢▢▢▢▢                           │  ← ячейки ядер, крупнее для старших кластеров
│ Performance                      │
│ ▫▫▫▫▫▫▫▫▫▫▫▫                     │
│ GPU                          4%  │
│ ▮▯▯▯▯▯▯▯▯▯▯▯▯▯▯▯▯▯▯▯               │  ← 20 полосок, загораются слева направо
╰──────────────────────────────────╯
Процессор   [мини-график]       23%
Память      [мини-график]  14.2 / 48 ГБ
Сеть        [мини-график]  ↓2.4 ↑0.1 МБ/с
Диск        [мини-график]  212 ГБ своб.
──────────────
Xcode                 142%    3.1 ГБ   ← топ-3 по CPU
Safari                 18%    1.2 ГБ
Music                   6%    410 МБ
──────────────
Настройки                     Выход
```
- **Кластеры** — из `CPUStats.clusters` (имена из `hw.perflevelN.name`), порядок level 0 первым; ячейки ядер кластера — из `CPUStats.cores` с тем же `level`. Размер ячейки: level 0 — 22 pt высоты, остальные — 16 pt; ширина делится поровну в ряду.
- **Цвет ячейки** — `HeatScale` по загрузке ядра.
- **Подсказка** (`.help`) на ячейке: «Ядро N · <кластер> · NN %».
- **GPU**: число горящих полосок = `round(загрузка/100 × число полосок)`, минимум 1 при загрузке > 0; цвет горящих — `HeatScale` по общей загрузке GPU, а ниже 20 % — нейтральный `primary` 50 % (иначе горящие полоски не отличить от негорящих). Полосок не больше 40 (`GPUBars.maxBars`); кластеры больше 12 ядер переносятся на несколько рядов поровну (`DieMapRows`). Число полосок = число ядер GPU (`gpu-core-count` из IORegistry `IOAccelerator`; нет данных → 16).
- **Клик по линзе** открывает вкладку CPU.
- **Строки метрик**: название (secondary), монохромный мини-график за 10 минут, значение (primary). Активное оповещение → значение и график в «Жар».
- Нет данных метрики → строка скрывается (как в базовой спецификации).

### 4.3 CPU
Большая карта кристалла (ячейки ~28 pt, процент внутри ячейки), ниже графики «Всего» и по каждому кластеру: линия + мягкая вертикальная заливка, без сетки, подписи 0 / 50 / 100 % справа мелким шрифтом.

### 4.4 Память
Горизонтальная составная полоса «Приложения / Wired / Сжатая / Кэш» в четырёх оттенках `primary` (100 / 70 / 45 / 25 % непрозрачности) с подписями значений; давление памяти: «Нормальное» нейтрально, «Повышенное» — янтарь, «Критическое» — жар; график использования за 10 минут; swap строкой.

### 4.5 Сеть
Один зеркальный график: приём — область вверх от оси, отдача — вниз; подписи пиков; интерфейс и итоги с запуска строками.

### 4.6 Диск
Тонкие полосы заполнения томов (жар, если свободно < 10 %), зеркальный график чтения (вверх) / записи (вниз).

### 4.7 Сенсоры (в «Ещё»)
Как сейчас (группа CPU со сворачиванием, SSD, Батарея, Контроллер питания, вентиляторы, GPU, мощность, батарея); значения температур окрашены по температурной шкале §3.2.

### 4.8 Процессы (в «Ещё»)
Переключатель «CPU / Память»; у строки тонкая полоска доли (CPU % / 100 % на одно ядро, обрезка до ширины) цвета `HeatScale` по CPU %.

## 5. Строка меню — мини-кристалл

- Пункт настроек `MenuBarItem.icon` переименовывается в интерфейсе в **«Мини-кристалл»** и рисует сетку ядер вместо значка `gauge.medium` (сырое значение `icon` сохраняется для совместимости настроек).
- Значения по умолчанию для новых настроек: `[.icon, .temperature]`. Сохранённые настройки не меняются.
- **Раскладка** (`MiniDieLayout`, в MetricsCore): ячейка 4×4 pt, промежуток 1.5 pt, максимум 3 ряда.
  - Правило: кластеры идут level 0 первым; каждый кластер начинается с новой строки и занимает `ceil(размер / колонки)` строк; колонки = наименьшее `c ≥ 1`, при котором суммарное число строк ≤ 3. Если кластеров больше 3 — колонки подбираются так же, но ряды кластеров не разделяются (все ядра подряд).
  - Пример M5 Pro (6 + 12): c = 6 → 1 + 2 = 3 ряда. M1 (4 + 4): c = 4 → 2 ряда. M3 Max (12 + 4): c = 6 → 2 + 1 = 3 ряда. M2 Ultra (16 + 8): c = 8 → 2 + 1 = 3 ряда.
- **Цвет ячейки**: холодные — `labelColor` с прозрачностью 35 % (видно и в светлой, и в тёмной строке), нагретые — цвета шкалы.
- Остальные элементы строки меню (CPU %, RAM %, температура, сеть, мини-график) и подсветка при оповещениях — без изменений.

## 6. Окно настроек
Нативная `Form` (`.formStyle(.grouped)`) — на macOS 26 она уже стеклянная. Во вкладке «Строка меню» сверху — живой предпросмотр значка (тот же рендер, что в строке меню). Размер окна подстраивается под содержимое вкладки (без пустого места).

## 7. Структура кода (изменения)

- `MetricsCore/Presentation/HeatScale.swift` — шкала нагрева: `HeatScale.color(forLoad:) -> HeatColor` (RGBA-компоненты или маркер «холодное стекло»), `HeatScale.temperatureLevel(_:)`.
- `MetricsCore/Presentation/MiniDieLayout.swift` — раскладка ячеек для строки меню.
- `MetricsCore/Presentation/GPUBars.swift` — `GPUBars.litCount(utilization:total:) -> Int` (число горящих полосок) и `GPUBars.defaultCount = 16`.
- `MetricsCore/Collectors/GPUCollector.swift` + `GPUStats` — добавить `coreCount: Int?` (`gpu-core-count`).
- `StatusApp/Popover/Components/` — `DieMapView` (линза с кластерами и GPU), `MetricRow`, `MirroredChart`, `StackedBar`, `GlassTabBar`; переработка существующих вкладок; `TileView` и `SparklineView` заменяются/удаляются, если не используются.
- `StatusApp/MenuBar/MenuBarRenderer.swift` — рендер мини-кристалла вместо иконки.
- `Package.swift`, `Resources/Info.plist` — macOS 26.

## 8. Тестирование
- **Юнит-тесты (MetricsCore, TDD):** `HeatScale` (границы 0/20/60/90/100 %, интерполяция в середине отрезков, температурные ступени), `MiniDieLayout` (M5 Pro, M1, M3 Max, M2 Ultra, одно-кластерный fallback «CPU», 0 ядер), число горящих полосок GPU (0 %, 1 %, 50 %, 100 %, нет числа ядер).
- **Визуальная проверка:** PNG через `-SnapshotDir` для всех вкладок, строки меню и настроек; если офскрин-рендер не рисует стекло — финальная визуальная проверка пользователем.
- **Ресурсы:** замер ≥ 60 с при закрытой панели: CPU < 1 %, phys_footprint < 50 МБ.
